# 验证层

运行 node --test tests/*.test.mjs。测试覆盖样例结果、独立解法交叉验证、分支、阶段映射、轨迹不可变性、大输入窗口和部分挂载/清理行为。

pnpm check 检查 Astro/TypeScript；多语言执行另见 scripts/verify-algorithm-languages.mjs。映射存在不代表所有语言均已编译或执行。

Node 生命周期测试使用简化 DOM，不能替代浏览器检查。交互修改还需验证站内导航、样本切换归零、前后步进、拖动、高亮、复制、展开与主题。进度栏必须只有两颗规定按钮和进度条。

不为单纯格式或说明文档编写镜像测试；增加功能时验证具体行为与边界。
