## 从一小段代码开始

这是一篇展示中文排版与代码块的示例笔记。

```python
def greet(name):
    return f"你好，{name}！"

print(greet("mini_taitan"))
```

`name` 是传入函数的参数，`return` 把结果交给调用函数的位置。先用一个简单例子观察输入和输出，再慢慢增加复杂度。

## 把过程写清楚

记录代码时，可以依次写下问题、自己的想法、一个具体例子和最后的实现。比起只保存代码，留下当时的思路更方便以后复习。
