## 拆分方案

### 01：暂时隐藏非 LeetCode 文章

**Blocked by:** None（可立即开始）。

**交付：** 首页到文章详情及订阅、搜索统一聚焦现有 LeetCode 专题，其他文章保留内容、可恢复。

**验收：**

- 17 篇 Hot 100 专题继续可访问，独立关于页面保留。
- 非 LeetCode 正文、元数据及关联资源没有被删除。
- 首页、归档、分类、标签、文章跳转、RSS、站点地图和搜索一致排除隐藏文章。
- 隐藏文章详情不公开正文，开发与生产构建一致。
- 记录恢复方式，并完成浏览器与构建输出检查。

### 02：状态栏双击切换示例

**Blocked by:** None（可立即开始）。

**交付：** 解答顶部状态栏一次双击切换一个示例，执行状态同步归零，键盘导航正常。

**验收：**

- 单击不切换，双击只切一次，末尾循环到第一例。
- 输入、变量、输出、说明及逐语言代码高亮同步到初始状态。
- Shift+Tab 提示、声明和拦截移除，正常反向焦点导航恢复。
- 聚焦样本入口后 Enter／空格可切换。
- 状态栏不最大化，代码区域双击最大化保留。
- 多卡片独立，换页后无重复监听；算法进度栏不改变。

### 03：通过题间分隔线收起解答

**Blocked by:** None（可立即开始）。

**交付：** 解答展开时原有紫线悬停变细，点击或键盘收起本题，不增加占位。

**验收：**

- 无额外文字按钮、箭头或布局高度。
- 悬停／聚焦粗线变细，线中心及上下布局稳定。
- 命中区域容易点击，不覆盖进度栏或下一题。
- 点击、Enter、空格都收起所属卡片；已收起时恢复普通分隔线。
- 复用原收起动作，焦点及视口返回本题入口，代码最大化恢复。
- 多卡片归属及页面生命周期正确；算法进度栏不改变。

### 04：实现小巧的一体化音乐播放器

**Blocked by:** None（可立即开始）。

**外部验收前提：** 用户尚未提供正式音频与封面资源。开发者可以使用合法的本地测试音频验证播放器，不把测试资源当作最终曲目；真实四曲播放验收需资源到位。

**交付：** 顶栏入口、最终 C 浮窗、可配置歌单及真实音频状态连成完整播放器，换页可续播。

**验收：**

- 入口位于搜索与调色板之间，按钮对齐，播放／停止图标跟随真实音频状态。
- 浮窗按最终约 360×222 的融合封面设计，左侧歌名作者上下排列，右侧仅歌名。
- 歌单直接内部滚动，首尾可居中；当前曲目与浏览焦点区分；减少动态效果设置生效。
- 进度条厚实，可拖动到真实音频位置，只显示当前时间，无右侧占位。
- 悬停选歌、点击播放／停止、换歌归零、停止后续播和换页持续播放有效。
- 资源缺失和加载失败显示真实状态，不假报播放成功；无重复音频实例和陈旧事件。
- 四首示例及作者可配置，使用有效资源完成测试；用户资源到位后验收正式歌单。
- 深浅色、主题色和窄屏可读；无额外浮窗音量、歌词或控制区。

这是一项播放器完整纵向任务，界面与音频管理不拆成两张互相无法独立演示的票。

### 05：稳定数组、一维 DP 与矩阵动画

**Blocked by:** None（可立即开始）。

**交付：** 数组及矩阵类题卡按样本预留空间，单步、回退及拖动均不改变外框及格子尺寸。建立供其他渲染器使用的样本布局边界接入方式。

**验收：**

- 杨辉三角五行、数组／一维 DP、二维 DP 的代表样本全过程布局稳定。
- 格子、字体、状态标签占位及结构锚点稳定，算法必要的高亮和指针移动正常。
- 切样本／视口变化允许重新计算边界；普通步进不反复测量全部 DOM。
- 不写死 528px，不采用固定 260px 内部滚动画布；保留大输入的有限展示窗口。
- 布局边界接入方式兼容尚未迁移的渲染器，不能在这张票中破坏其他题型。
- 保留结果、不可变快照、步骤说明和多语言高亮；算法进度栏不改变。
- 完成前后步进、拖动、切样本、窄屏及相关算法回归验证。

### 06：稳定树与图动画

**Blocked by:** 05（复用已建立的样本布局边界接入方式）。

**交付：** 树、递归访问和图遍历在同一样本内有稳定画布与节点尺寸，节点访问、边和路径变化清楚呈现。

**验收：**

- 为树／图分别确定最大展示边界与稳定结构锚点，不强行使用数组或矩阵布局。
- 覆盖访问、队列变化、递归进入／返回及终态，不因标签或节点数量变化重新缩放整图。
- 真正的路径与节点变化仍按轨迹表现，多卡片及页面导航独立。
- 保留节点身份、省略说明、算法结果及语言高亮。
- 完成代表题、边界样本、前后步进、拖动和窄屏验证。

### 07：稳定链表动画

**Blocked by:** 05（复用已建立的样本布局边界接入方式）。

**交付：** 链表指针修改、节点删除和重排不改变无关节点大小或画布高度，算法必要运动保留。

**验收：**

- 依据样本节点、稳定身份及指针展示确定边界，不依据每步可见元素重新缩放。
- 覆盖 next／random、删除、交换、反转及终态中的适用行为。
- 指针标签预留空间，空值和窗口省略可辨认。
- 算法快照、身份与结果不变，代码高亮同步。
- 完成代表题、单节点／空边界、前后步进、拖动和窄屏验证。

### 08：稳定回溯、堆与 Trie 动画

**Blocked by:** 05（复用已建立的样本布局边界接入方式）。

**交付：** 路径增长回退、堆变化和前缀树访问在各自稳定布局中呈现，不引起页面跳动。

**验收：**

- 各结构独立配置展示边界，不按题号堆条件分支，也不强制套用同一尺寸。
- 回溯覆盖选择、递归与撤销；堆覆盖添加／移除及必要交换；Trie 覆盖路径和终止标记。
- 路径、节点和标签尺寸稳定，实际算法运动保留。
- 保留原快照、结果、复杂度和逐语言高亮；算法进度栏不改变。
- 各渲染器至少验证代表题及边界样本，记录未覆盖内容。

这是本草案范围最宽的一项。如果审阅时希望更细，可按回溯、堆、Trie 拆为三票，依赖均为 05。

### 09：集成验收并移出原型入口

**Blocked by:** 01、02、03、04、05、06、07、08。

**交付：** 正式页面完整呈现所有已确认行为，不再依赖开发原型或 variant 参数，并有完整验收记录。

**验收：**

- 每张票包含自身验证；本票只负责跨功能、正式页面及生产构建集成验收。
- 集成状态下音乐、收起、双击样本和稳定动画同时有效，不互相覆盖样式或事件。
- 首页到专题、同页多卡片、跨页导航、深浅主题及窄屏整体验收通过。
- 原型代码与截图作为设计证据归档，正式页面移除原型入口、切换栏及假播放状态；不删除唯一证据。
- 所有算法进度栏符合永久约束，结果与轨迹回归通过。
- 完成静态检查、算法测试、生产构建和差异检查，记录浏览器检查范围及剩余限制。
- 若正式音乐资源未到位，不将该项或整体任务标记为全部验收完成。
